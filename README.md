# Optimal-btd6

OptimalBtd6 is a static HTML/CSS/JavaScript website for unofficial BTD6 farming and planning calculations.

## Static site structure

- `index.html` - GitHub Pages entry point and static app shell.
- `css/style.css` - App styling and responsive layout.
- `js/app.js` - Main client-side app state, rendering, interactions, rule checks, and calculator hooks.
- `data/images.js` - Icon/image key lookup used by the UI and tower data.
- `data/towers.js` - Hero, Geraldo item, and tower metadata.
- `data/roundIncome.js` - Per-round pop-income table.

## Project constraints

- Keep the site static and GitHub Pages compatible.
- Do not add a backend.
- Keep the app plain HTML/CSS/JavaScript unless a framework is explicitly requested.
- Prefer small, reviewable changes.
